# Qwen3-1.7B 三组补充实验

本目录使用本地 `assets/qwen3-1.7b` 的 BF16 权重真实执行模型，补充验证分割正确性、安全—可用性权衡和调度优化趋势。目标机器只有 CPU 和 16 GB 内存，因此模型只加载一次；500 km / 10 Gbps 链路与单云执行槽由测得的真实服务时间驱动回放。

## 一键复现

```powershell
cd .\interview-challenge
powershell -ExecutionPolicy Bypass -File .\qwen3-validation\run.ps1
```

默认使用3个中英文问题、每题生成4个Token、容量实验8个请求。完整执行约82秒。结果写入 `results/qwen3-1.7b-three-experiments.json` 和 `results/qwen3-1.7b-security-utility.svg`。

## 实验一：原始与分割路径对齐

| 指标 | 结果 |
|---|---:|
| 问题数 | 3 |
| 逐Token完全一致 | 3/3 |
| 平均Token一致率 | 100% |

两条路径使用相同Qwen3-1.7B BF16权重和Greedy Decode。分割路径显式经过企业侧Embedding、云侧28层Transformer以及企业侧Norm/LM Head，并维护逐请求KV Cache。结果说明基础分割没有改变这3个样本的生成结果。这是短序列正确性验证，不等于完整问答质量评测；4个输出Token用于控制CPU实验时间。

## 实验二：安全—可用性权衡

在每次传输的Embedding上加入独立高斯噪声。攻击指标为已知Embedding表条件下的余弦最近邻Token恢复率；可用性指标为噪声输出相对无噪声输出的Token一致率。

| 噪声σ/Embedding RMS | 攻击恢复率 | 输出Token一致率 | 完全一致回答率 |
|---:|---:|---:|---:|
| 0 | 100.0% | 100.0% | 100.0% |
| 0.5 | 100.0% | 91.7% | 66.7% |
| 1 | 100.0% | 33.3% | 0.0% |
| 2 | 97.8% | 16.7% | 0.0% |
| 4 | 80.4% | 8.3% | 0.0% |
| 8 | 65.2% | 25.0% | 0.0% |
| 16 | 4.3% | 16.7% | 0.0% |
| 32 | 0.0% | 16.7% | 0.0% |

核心结论：在攻击恢复率仍为100%的1倍噪声处，输出一致率已降至33.3%；要把攻击恢复率压到接近0，需要16～32倍噪声，而输出早已不可用。这支持“朴素加噪无法同时保证隐私和生成可用性”的结论。

高噪声区的输出一致率不严格单调，是因为仅有3个提示、每题4个输出Token，随机错误Token偶然相同会造成波动；是否可用应结合完全一致率（从1倍噪声起始终为0）判断。

## 实验三：原始/分割 × 串行/流水线

模型真实执行测得的平均Prefill和Decode单步耗时作为单云执行槽服务时间，再叠加500 km传播时延和10 Gbps序列化时延，对8个请求进行确定性调度回放：

| 模型路径 | 调度 | 吞吐(QPS) | 云槽利用率 | 总耗时 |
|---|---|---:|---:|---:|
| 原始模型 | 串行 | 0.708 | 99.65% | 11.307s |
| 原始模型 | 流水线 | 0.710 | 99.96% | 11.272s |
| 分割模型 | 串行 | 0.698 | 98.25% | 11.468s |
| 分割模型 | 流水线 | **0.710** | **99.96%** | **11.272s** |

相对分割串行，分割流水线吞吐提高约1.73%，并把云槽利用率从98.25%提高到99.96%。流水线几乎消除了分割链路等待，但绝对收益较小，因为本机CPU模型计算耗时远大于约20ms的累计网络等待。该结果验证的是机制和方向，不能外推为8×H20上的收益幅度。

## 证据边界

- 真实部分：Qwen3-1.7B BF16权重、Embedding、28层Transformer、LM Head、KV Cache、Greedy生成及服务时间。
- 模拟部分：500 km / 10 Gbps链路和单执行槽调度；本机没有真实WAN和多GPU。
- 无法覆盖：Qwen3-32B、企业2卡+云端8卡、Tensor Parallel/NCCL、GPU动态Batch和真实网络抖动。
- 因此，本实验用于证明实现正确性与相对趋势；目标硬件绝对QPS仍使用Q4容量模型并等待GPU实测校准。

## 补充：分割模型 GSM8K

Qwen3-1.7B BF16 分割模型在 GSM8K 前50题答对27题，准确率54%；已有Q4原始模型结果为28/50（56%）。在相同前10题的噪声消融中，无噪声、0.5倍噪声和1倍噪声分别答对4、3、0题。详细方法、解释和证据边界已写入 [`../q2-split-inference/README.md`](../q2-split-inference/README.md)。

cd .\interview-challenge
